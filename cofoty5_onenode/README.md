# CoFoTy5 OneNode ® (cofoty5_onenode)

노드 하나로 Anima(또는 Illustrious 등 체크포인트) 이미지를 만드는 간편판입니다. WebUI처럼 **프롬프트 → 생성 → 마음에 드는 한 장 고르기 → 저장**만 하면 됩니다.

> 라이선스: GPL-3.0 (`LICENSE`). ComfyUI와 같은 라이선스입니다.

## 화면 구성
**3단(기본)**: 설정 | 프롬프트 | 미리보기.  **2단**: 왼쪽 설정 | 오른쪽 프롬프트 + 미리보기
- 프롬프트 맨 위 **[◧ 2단] / [▥ 3단]** 로 바꿉니다. 바꾸면 노드 크기와 화면이 알맞게 맞춰집니다.
- 메뉴 **CoFoTy5 OneNode › OneNode 노드를 화면에 꽉 차게** 로 언제든 노드를 화면에 맞출 수 있습니다. 처음 설치 후 켜면 자동으로 맞춰집니다.
- 칸 높이는 2단 · 3단을 따로 기억합니다.
- **세로줄**을 끌면 열 폭이, **가로줄**을 끌면 칸 높이가 바뀝니다. 두 번 누르면 기본값. 노드마다 기억합니다.

**왼쪽 — 설정**
- **① 모델 설정** (제목을 눌러 통째로 접기): 스텝 · CFG · 샘플러 · 스케줄러 · 시드(랜덤/고정). 모델 · 인코더 · VAE는 한 번 더 접혀 있습니다.
  - 샘플러 = 그리는 방법, 스케줄러 = 단계마다 노이즈를 얼마나 걷어낼지 정하는 순서
  - 기본값: Anima 터보 · 12스텝 · CFG 1.5 · er_sde · beta57
  - 제목 옆 표시: **ANIMA**(청록) / **SDXL·IL**(주황) — 지금 어떤 종류의 모델을 쓰는지
  - 모델 목록에는 Anima(`models/diffusion_models`)와 체크포인트(`models/checkpoints`)가 함께 나옵니다. 고르면 종류가 저절로 바뀝니다.
  - 종류를 바꾸면 스텝 · CFG · 샘플러 · 스케줄러 · 업스케일 샘플러 · 품질 태그 · 부정 프롬프트 · LoRA가 그 종류용으로 바뀝니다.
    처음엔 기본값(체크포인트: 28스텝 · CFG 5.5 · euler_ancestral · normal), 그다음부터는 그 종류에서 마지막으로 쓰던 값.
  - 체크포인트일 때: 인코더 · VAE 칸은 잠기고(파일 안에 들어 있음) **CLIP Skip**(기본 2)이 보입니다.
- **② 크기 · LoRA**: 배치(한 번에 몇 장, 기본 1장) · 비율(1:1, 3:4 등) · 세로/가로, 그리고 LoRA 목록
  - **+ LoRA 추가**: 미리보기 그림이 있는 목록에서 고릅니다 (마우스를 올리면 크게 보기)
  - 줄마다 켜기/끄기 · 세기 −/+ · 끌어서 순서 바꾸기 · 그림을 눌러 다른 LoRA로 바꾸기
  - 키워드 칩을 누르면 긍정 프롬프트에 넣고 뺍니다 · **저장**으로 지금 조합을 세트로 저장
  - LoRA는 지금 모델 계열용만 보여 줍니다(**지금 모델용만** 체크를 끄면 전부). 계열이 다르면 줄에 빨간 ⚠ 표시
  - **로라 프롬프트** 칸(LoRA 목록 위): 작가 태그 등. 생성할 때 **품질 바로 뒤에 무조건** 들어갑니다(품질을 꺼도 들어감, 중복은 따지지 않음)
  - 세트 = LoRA 목록 + 모델 종류 + 로라 프롬프트. 세트를 고르면 로라 프롬프트 칸도 그 세트 것으로 바뀝니다(저장 안 된 예전 세트는 빈 칸)
  - 세트 이름 앞 글자: **An** = Anima용, **IL** = SDXL·IL용, **15** = SD1.5용. **필터**(지금 모델용만)를 켜면 다른 모델용 세트는 흐리게 보이고 고를 수 없습니다
  - 세트 줄 버튼: **저장** · **삭제**(한 번 더 눌러야 지워짐) · **폴더**(저장 위치) · **필터**(지금 모델용만, LoRA 고르기 창의 체크와 같은 스위치)
  - 폴더(저장 위치): LoRA 세트 · 태그 사전 · 고친 한글 뜻 · 번역 저장이 함께 저장됩니다. 기본은 `ComfyUI\user\cofoty5`이라 따로 깐 ComfyUI와는 섞이지 않습니다. ComfyUI 폴더를 지우면 함께 지워집니다. 다른 폴더를 고르면 그쪽만 따로 씁니다(비워서 적용하면 기본으로 복귀). 처음 실행할 때 노드팩 폴더의 예전 파일은 한 번 합쳐집니다.
- **③ 업스케일 · 보정** (제목을 눌러 통째로 접기): 업스케일 배율 1.25 · 디노이즈 0.35 · er_sde/simple, 얼굴 · 손 보정 켜기와 세기
- **④ 목록으로 연속 생성** (처음엔 접혀 있음): 엑셀 · CSV · 메모장에 적은 항목을 체크해서 항목마다 이어서 생성 ([아래](#목록으로-연속-생성))

**프롬프트 칸** (위에서부터 이 순서로 이어 붙여 씁니다)
| 칸 | 쓰는 것 | 높이 |
|---|---|---|
| 품질 · 작가 태그 | 품질 태그, 작가 태그. 체크를 끄면 안 붙음. [품질 태그 숨기기]로 감출 수 있음 | 고정 (가로줄로 조절, 길면 스크롤) |
| 긍정(본) 프롬프트 | 그리고 싶은 것 | 남는 높이를 모두 차지 |
| 배경 · 기타 | 장소 · 조명 · 구도 등 | 고정 (가로줄로 조절) |
| 부정 프롬프트 | 나오지 않았으면 하는 것 | 고정 (가로줄로 조절) |
| 구도 버튼 | 앵글 · 프레이밍 · 시선 · 자주 쓰는 (제목을 눌러 접기) | 내용만큼 (2단에서는 길면 스크롤) |

**구도 버튼**: 눌러서 켜면 그 태그가 본 프롬프트 뒤, 배경 앞에 붙습니다 (프롬프트 글자는 바뀌지 않음, 제목 줄에 켜진 태그 표시).
- 앵글 · 프레이밍 · 시선은 여러 개를 함께 켤 수 있습니다 (다시 누르면 꺼짐).
- **자주 쓰는**: `dynamic pose` · `dynamic angle`이 처음부터 들어 있고(✎로 지울 수 있음), **+ 추가**에 `웃음=smile` 또는 `smile, blush`를 넣으면 내 버튼이 생깁니다. **✎**를 누르면 × 로 지울 수 있습니다.
  `ComfyUI/user/cofoty5_onenode_favs.json` 에 저장되어 노드를 업데이트해도 남습니다.

**‹ ›** (프롬프트 제목 옆): 이전 / 다음 프롬프트. [생성]할 때마다 네 칸과 구도 버튼을 기억해 두고 오갈 수 있습니다. 고치던 중에 뒤로 가도 앞으로 끝까지 오면 고치던 내용이 돌아옵니다. (ComfyUI를 끄면 지워짐)

**[한→영]**: 네 칸의 한글을 영어로 바꿉니다. 영어 태그는 그대로 둡니다.
- 단어(웃음, 금발, 교복 …)는 한국어 Danbooru 태그 사전(chiharoong/danbooru-tags-kr, MIT)으로 정확한 태그로 → `smile`, `blonde hair`
- 문장은 구글 번역으로 영어 문장 → Anima는 영어 문장도 잘 알아듣습니다
- `(웃음:1.2)` 처럼 가중치는 그대로 살립니다 · **↶ 되돌리기**로 번역 전으로
- 사전은 처음 번역할 때 받을지 물어봅니다
- 구글 번역은 무료 비공식 주소라 인터넷이 필요하고, 많이 쓰면 잠시 막힐 수 있습니다. 못 바꾼 조각은 한글 그대로 남고 상태 줄에 표시됩니다.

**[한글로 잠깐 보기]**: 네 칸을 한글로 옮겨 **보여주기만** 합니다. 다시 누르거나(버튼이 [영어 원문 보기]로 바뀜) 한글 칸을 누르면 영어로 돌아옵니다.
- 프롬프트 글자는 그대로이고 생성에도 영어 원문이 쓰입니다. 영→한→영으로 다시 번역하지 않으니 원문이 바뀌지 않습니다.
- 태그는 사전으로, 사전에 없는 태그 · 문장은 구글 번역으로 옮깁니다. 못 옮긴 조각은 영어 그대로 보입니다.

**출력**: 미리보기 → **▶ 생성** · **💾 그대로 저장** · **⬆ 업스케일 저장** → **저장** 칸(output 안 폴더 · 파일 이름 규칙 · 날짜별 폴더 · 📂 폴더 열기)
- 저장하면 결과가 크게 뜨고(금색 표시), 미리보기 줄 오른쪽에 저장본(⬆ / 💾)이 쌓입니다. 눌러서 다시 볼 수 있습니다.
- 저장본을 볼 때 오른쪽 아래 **[◐ 누르고 있으면 원본]** 을 누르고 있으면 저장 전 그림이 보입니다 (업스케일 전후 비교).
- 새로 생성하면 저장본 줄은 비워집니다 (파일은 그대로 저장 폴더에 있음).
- **저장본을 고른 상태**에서는 버튼이 바뀝니다: **⬆ 저장본 다시 업스케일**(한 번 더 키우기) · **💾 보정해서 저장**(손 · 얼굴 보정만, 보정을 켜야 누를 수 있음).
  다시 키운 결과가 약 2.6MP(예: 1360×1792 → 1700×2240)를 넘으면 그래픽카드 메모리 경고를 먼저 보여 줍니다.
- 시드가 **랜덤**이면 업스케일 · 보정도 누를 때마다 새 시드를 써서 같은 그림이라도 결과가 조금씩 다릅니다. 손 모양이 마음에 안 들면 몇 번 더 눌러 보세요.
  **고정**이면 같은 그림은 매번 같은 결과가 나옵니다. 쓴 시드는 저장 PNG에 기록됩니다.

## 쓰는 법
1. **긍정 프롬프트**에 그리고 싶은 것을 영어 태그로 적습니다. (예: `1girl, solo, smile, long hair, school uniform`) 한글로 쓰고 [한→영]을 눌러도 됩니다.
2. 왼쪽에서 **배치 · 비율**을 고르고 (필요하면 LoRA 추가) **▶ 생성**을 누릅니다.
3. 미리보기 아래 작은 그림을 눌러 **한 장을 고릅니다.** 큰 그림을 누르면 새 창에서 원본 크기로 보입니다.
4. **💾 그대로 저장** 또는 **⬆ 업스케일 저장**(키우고 다듬어 저장). 손 · 얼굴 보정이 켜져 있으면 저장할 때 함께 적용됩니다.

- 위쪽 [실행(Run)] 버튼을 눌러도 **생성**과 같습니다.
- 시드를 **고정**으로 바꾸면 시드가 고정됩니다. 마지막으로 쓴 시드가 칸에 남아 있으니, 마음에 든 결과에서 랜덤을 끄면 그 시드로 계속 쓸 수 있습니다.
- 미리보기는 ComfyUI를 재시작하면 지워집니다(임시 파일). 마음에 드는 건 바로 저장하세요.
- 워크플로 탭을 바꿨다 돌아와도 미리보기 · 저장본 줄 · 목록으로 연속 생성 진행 상태가 그대로 남아 있습니다. (화면 새로고침 · ComfyUI 재시작 때는 비워짐)
- 프롬프트 안에 `<lora:파일이름:0.8>`을 적어도 LoRA가 적용됩니다 (LoRA Manager의 문법 복사와 호환).

## 목록으로 연속 생성
엑셀 · 메모장에 적어 둔 **항목**(표정 · 포즈 · 의상 등)을 체크하면, 항목마다 태그를 붙여 **한 번에 이어서 생성**합니다.
모델 · 크기 · LoRA · 프롬프트 · 구도 버튼은 지금 설정 그대로이고 항목 태그만 바뀝니다. 노드 안 **? 사용법** 버튼으로 같은 안내를 볼 수 있습니다.

1. **📂**으로 항목 폴더 `ComfyUI/input/onenode`를 열고 파일을 넣은 뒤 **↻** (처음엔 `항목_예시.xlsx` · `항목_예시.txt`가 들어 있음)
2. 파일을 고르고 만들 항목을 체크 (분류 제목 = 그 분류 전체, 찾기 · 전체 · 해제)
3. 진행 방식을 고르고 **▶ 시작**
   - **⚡ 바로 저장**: 끝까지 자동으로 만들고 나온 그림을 전부 그대로 저장
   - **⚡ 업스케일 저장**: 끝까지 자동으로 만들고 전부 업스케일해서 저장 (③ 설정, 보정 포함)
   - **👀 보면서 진행**: 한 항목씩 만들고 멈춤. 오른쪽 버튼:
     **⏭ 다음 생성** · **💾 그대로 저장** · **⬆ 업스케일 저장**(고른 한 장) · **💾 모두 그냥 저장** · **⬆ 모두 업스케일 저장**(미리보기 전부)
     — 여러 번 저장해도 되고, 다 되면 **⏭ 다음 생성**. **☑ 저장하면 자동 다음 생성**을 켜면 저장 한 번에 바로 다음 항목

- 항목마다 **② 배치** 장수만큼 만듭니다 (항목 10개 × 배치 2장 = 20장).
- 항목 태그는 본 프롬프트 → 구도 버튼 → **항목 태그** → 배경 · 기타 순서로 붙습니다.
- 저장 파일 이름 앞에 항목 이름이 붙습니다: `웃음_20261111_0001.png`. PNG 설정 글에도 `Item: 웃음`이 남습니다.
- ⚡ 방식은 항목마다 ComfyUI 대기열에 하나씩 들어가 자리를 비워도 끝까지 돕니다. ④의 **■ 그만**은 남은 대기열을 지우고 멈춥니다 (보면서 진행도 ■ 그만으로 끝냄).
- 시드 **고정**이면 모든 항목이 같은 시드 → 표정 · 포즈만 비교하기 좋음. **랜덤**이면 항목마다 다른 그림.

**항목 파일 작성법** (엑셀 .xlsx · CSV · TSV · 메모장 .txt)
- 엑셀: 첫 줄 제목 `이름 | 태그` (또는 `분류 | 이름 | 태그`). **시트 하나 = 분류 하나**. 분류 칸이 비면 위 줄 분류를 이어받음
- 이름이 `#`으로 시작하는 줄 · 시트는 메모로 무시. 태그 칸이 빈 줄은 건너뜀. 태그에 `<lora:이름:0.8>`을 쓰면 그 항목에만 LoRA
- 구글 스프레드시트: **파일 → 다운로드 → Microsoft Excel(.xlsx)** 또는 CSV로 받아 폴더에 넣기 (`.gsheet` 바로가기는 못 읽음)
- CSV: 엑셀과 같은 열. 한글 엑셀 CSV(CP949)와 UTF-8 모두 읽음
- 메모장: 한 줄에 `이름 = 태그` (태그만 써도 됨), `[분류]` 줄로 묶기, `#` 줄은 메모

## 가속 (⚡)
① 모델 설정 제목 줄의 **⚡ 가속** 표시 — 설치할 때 설치 프로그램에서 가속 기능을 골랐거나, 한 번 시험한 뒤에 켜짐 / 사용 불가가 표시됩니다.
- **켜짐 / 꺼짐**: 눌러서 바꿉니다(모든 OneNode에 같이 적용). 켜져 있으면 생성 · 업스케일 · 손얼굴 보정에 Sage Attention과 fp16 누적을 씁니다.
- **시험 안 함**: 설치 프로그램 없이 노드 폴더만 복사한 경우입니다. 눌러서 시험하면 결과에 따라 켜짐 / 사용 불가로 바뀝니다.
- **사용 불가**: 이 PC에서 시험을 통과하지 못했거나, 쓰는 중 오류가 난 경우입니다. 마우스를 올리면 이유가 보이고, 스위치는 눌러지지 않습니다. 옆의 **다시 시험**으로 다시 확인합니다.
- 상태 파일: `ComfyUI/user/cofoty5_accel.json` (시험: `accel_test.py`)

## 위쪽 상태 표시줄
메뉴 바에 `CPU · RAM · GPU · VRAM · 온도(C/G) · ↻ 리셋`이 표시됩니다.
- **↻ 리셋** = ComfyUI 재시작. 절전 모드에서 깨어난 뒤 GPU를 못 잡을 때 누르세요. (GPU 칸이 빨간 **끊김**으로 바뀌면 리셋이 필요하다는 뜻)
- CPU 온도는 LibreHardwareMonitor를 관리자 권한으로 켜고 Options › Remote Web Server › Run을 켜 두면 표시됩니다.
- 같은 기능(상태 표시줄 · 리셋)이 있는 다른 노드팩이 같이 깔려 있으면 그쪽 표시줄만 보입니다.
